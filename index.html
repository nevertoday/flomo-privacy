Flomo 快捷发布 — 隐私政策

最后更新日期：2026 年 2 月 9 日

概述

「Flomo 快捷发布」是一款浏览器扩展程序，帮助用户将网页内容快速发送到 Flomo 笔记服务。我们重视您的隐私，本政策说明我们如何收集、使用和保护您的数据。

我们收集的数据

  • 用户主动选择的网页内容：仅当用户主动选中文字或图片并点击发送时，扩展才会处理该内容。我们不会自动采集任何网页内容。
  • 页面标题和 URL：发送笔记时可附带当前页面标题和链接，作为笔记来源参考。此信息仅在用户主动发送时获取。
  • 账户信息：如果用户选择登录会员服务，我们会通过 Supabase 认证服务处理登录凭证（邮箱和密码）。
  • 插件设置：API 地址、提示词配置、界面偏好等设置存储在浏览器本地（chrome.storage）和服务端。

我们不收集的数据

  • 我们不会监控、记录或分析您的浏览历史
  • 我们不会收集您的个人身份信息（姓名、地址、电话等）
  • 我们不会追踪您的点击、滚动或键盘操作
  • 我们不会将您的数据出售给第三方

数据如何使用

  • 用户选中的内容仅用于发送到用户自己的 Flomo 账户
  • 如果用户启用 AI 提示词功能，选中内容会发送到用户自行配置的 AI 服务接口进行处理
  • 会员登录信息仅用于身份验证和功能授权

数据存储

  • 插件设置存储在浏览器本地 (chrome.storage.local)
  • 会员认证数据通过 Supabase 云服务管理
  • 我们不会在自有服务器上存储用户的笔记内容

第三方服务

本扩展可能与以下第三方服务交互，具体取决于用户配置：

  • Flomo (flomoapp.com)：笔记存储服务
  • Supabase：用户认证与会员管理
  • 用户自配置的 AI 服务：内容处理（由用户自行提供 API 密钥）

数据安全

所有网络通信均通过 HTTPS 加密传输。用户的 AI API 密钥仅存储在浏览器本地，不会上传到我们的服务器。

用户权利

您可以随时卸载本扩展以停止所有数据处理。卸载后，浏览器本地存储的所有数据将被清除。

政策变更

如本政策有更新，我们会在此页面发布修订版本并更新日期。

联系方式

如有隐私相关问题，请通过 Chrome Web Store 的开发者联系方式与我们沟通。
